What is SPS? 
------------
Instead of manually setting a learning rate, SPS computes it automatically at each iteration using: η_t = c * (f(x_t) - f_est) / ||∇f(x_t)||²

python SPS.py --optimizer Adam --epochs 10 --runs 1
python SPS.py --dataset boston --model mlp --optimizer Adam --epochs 1000 --runs 5

Where:
- f(x_t) = current loss
- f_est = estimated minimum loss (tracked with EMA)
- ||∇f||² = gradient norm squared
- c = scaling factor (main hyperparameter)
Why It's Revolutionary:

✅ NO LEARNING RATE TUNING needed!
✅ Larger steps when far from optimum
✅ Smaller steps when close to optimum
✅ Automatic adaptation throughout training

Parameters Explained
--------------------
c - Step Size Scaling Factor
Default: 0.1
Range: 0.01 - 0.5
Most Important Parameter!

Controls how aggressive the automatic step size is
Higher c = faster convergence (but less stable)
Lower c = slower convergence (but more stable)

Tuning Guide:
Small datasets: c = 0.05
Medium datasets: c = 0.1 (default)
Large datasets: c = 0.15-0.2
Unstable training: c = 0.02-0.05
Too slow: c = 0.2-0.3

eta_max (η_max) - Maximum Step Size
Default: 10.0
Range: 1.0 - 100.0
Safety Cap:

Prevents extremely large steps
Acts as upper bound on automatic LR

Tuning Guide:
Training diverges: reduce to 5.0 or 2.0
Too slow: increase to 20.0 or 50.0
Generally safe to keep at default

momentum - Loss Estimate Momentum
Default: 0.9
Range: 0.8 - 0.99
Smooths Loss Estimate:

Higher = more stable estimate (slower adaptation)
Lower = faster adaptation (more noise)

Formula: f_est = momentum * f_est + (1-momentum) * min(f_current, f_est)
Tuning Guide:
Noisy loss: 0.95-0.99
Smooth loss: 0.85-0.9
Generally safe at default 0.9

---------------------------

------------------------------------------------------------

Pattern:
Early: Small steps (exploring)
Mid: Larger steps (making progress)
Late: Small steps (converging)

All automatic - no manual LR schedule needed!

Theory: Why SPS Works
Classic Polyak Step Size (1987):
For convex functions with known optimum f*:
η = (f(x) - f*) / ||∇f||²
Guarantees convergence in one step (deterministic case)!
SPS Innovation:

Don't know f?* → Estimate it with moving minimum
Stochastic gradients? → Use same formula anyway
Might explode? → Add safety cap (η_max)

Result:
Near-optimal automatic learning rate without tuning!

Quick Parameter Guide
------------------------
By Dataset Size:
Small (< 1000): --c 0.05 --eta-max 5.0 --momentum 0.95
Medium (1000-10000): --c 0.1 --eta-max 10.0 --momentum 0.9
Large (> 10000): --c 0.15 --eta-max 15.0 --momentum 0.9

By Problem:
Training diverges: --c 0.02 --eta-max 2.0 --momentum 0.95
Too slow: --c 0.2 --eta-max 20.0 --momentum 0.85
Oscillating loss: --c 0.08 --eta-max 8.0 --momentum 0.95

Stuck in plateau: --c 0.3 --eta-max 30.0 --momentum 0.85
