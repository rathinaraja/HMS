What is Lookahead?
------------------ 
Lookahead maintains two sets of weights:
Fast weights (θ_fast): Explored by base optimizer (Adam, SGD, etc.)
Slow weights (θ_slow): Stable trajectory that pulls fast weights back

Every k steps:
  1. Update slow: θ_slow ← θ_slow + α(θ_fast - θ_slow)
  2. Reset fast:  θ_fast ← θ_slow
Visual Metaphor: Dog on a Leash 🐕

Dog = Fast weights (explores eagerly)
Owner = Slow weights (walks steadily)
Leash = Every k steps, owner pulls dog back

Config Parameters  
self.LOOKAHEAD_K = 5         # Sync period (was c, eta_max, momentum)
self.LOOKAHEAD_ALPHA = 0.5   # Slow step size (new concept!)

Quick Test: python LAO.py --optimizer Adam --epochs 10 --runs 1 --output ./results
Full Experiment: python LAO.py --dataset boston --model mlp --optimizer Adam  --epochs 1000 --runs 5 --output ./results
Custom Lookahead Parameters:
Conservative (maximum stability): python LAO.py --optimizer Adam  --k 3 --alpha 0.3  --output ./results
Balanced (default, works great): python LAO.py --optimizer Adam  --k 5 --alpha 0.5  --output ./results
Aggressive (maximum exploration): python LAO.py --optimizer Adam  --k 8 --alpha 0.6  --output ./results

Parameters Explained
--------------------
k - Synchronization Period
Default: 5
Range: 3 - 10

What it does: How many fast steps before slow weight update. Examples:
k=3:  [Fast→Fast→Fast→SYNC] [Fast→Fast→Fast→SYNC]
k=5:  [Fast→Fast→Fast→Fast→Fast→SYNC] [Fast→...
k=10: [Fast(10x)→SYNC] [Fast(10x)→SYNC]

Tuning:
Unstable training → k = 3 (frequent stabilization)
Normal training → k = 5 (default)
Stable training → k = 7-10 (more exploration)

α (alpha) - Slow Weights Step Size
Default: 0.5
Range: 0.3 - 0.8

What it does: How far slow weights move toward fast weights
Formula: θ_slow ← θ_slow + α(θ_fast - θ_slow)
Examples:
If fast=10, slow=0:
  α=0.3 → slow becomes 3 (30% of the way)
  α=0.5 → slow becomes 5 (50% of the way)
  α=0.8 → slow becomes 8 (80% of the way)

Tuning:
Need stability → α = 0.3-0.4
Balanced → α = 0.5 (default)
Need speed → α = 0.6-0.8

💡 How It Works (Visual Example)
Example: k=5, α=0.5, using Adam
Step 1-5 (Fast exploration with Adam):
  θ₀ --Adam--> θ₁ --Adam--> θ₂ --Adam--> θ₃ --Adam--> θ₄ --Adam--> θ₅ 
  Slow weights stay at φ₀ (not updated yet)

Step 5 (Synchronization):
  φ₁ = φ₀ + 0.5(θ₅ - φ₀)  ← Slow weights pull
  θ₅ = φ₁                  ← Fast weights reset

Step 6-10 (Continue...):
  φ₁ --Adam--> θ₆ --Adam--> ... --Adam--> θ₁₀
   
Pattern: Fast explores, slow stabilizes, periodic reset!

🎓 Theory: Why Lookahead Works
1. Variance Reduction
Fast weights see noisy gradients → oscillate
Slow weights average over k steps → smooth trajectory!
2. Implicit Regularization
Slow weights prevent overfitting to recent batches
Acts like a gentle pull toward more general solutions
3. Better Exploration
Fast weights can explore aggressively (even overshoot)
They know they'll be pulled back → more willing to explore!
4. Universal Wrapper
Works with ANY optimizer: SGD, Adam, RMSprop, RAdam, etc.
Just wrap it and get improvements!

🔧 Quick Parameter Guide
By Dataset Size:
Small (< 1000): --k 3 --alpha 0.4
Medium (1000-10000): --k 5 --alpha 0.5
Large (> 10000): --k 7 --alpha 0.5

By Problem:
Unstable training: --k 3 --alpha 0.3
Slow convergence: --k 8 --alpha 0.6
Stuck in local minimum: --k 10 --alpha 0.7

Overfitting: --k 5 --alpha 0.4  # Acts as regularization
