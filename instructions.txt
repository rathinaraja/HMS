global_summary.csv - contains aggregated results, including test loss, and is primarily used for final result presentation and comparison.
****_report.txt (per optimizer) - provides a detailed, optimizer-specific summary of training behavior and performance.
run_*_epoch_losses.csv - stores per-epoch loss values and can be used to plot training and validation loss curves.
Linear_regression.ipynb and Deep_learning.ipynb - serve as step-by-step reference notebooks illustrating the full workflow. These notebooks should be used as templates when adapting the pipeline to new datasets.

What needs to be done?
-----------------------
For each new dataset, create a dedicated folder and copy the relevant .ipynb and .py files from the Boston_dataset directory. The following steps must be completed for each dataset: In .ipynb file
+ Load the dataset.
+ Preprocess the data.
+ Split the data into training and testing sets (80:20).
+ Define the model - for deep learning models, adjust the number of layers and neurons as required.

After validating the changes in the .ipynb files, port the modified code blocks into the corresponding .py scripts.
Run the Python script with appropriate arguments to perform 10 independent runs with 1000 epochs each. This will generate a results directory containing all output files listed above.

Note: 
+ The provided data_loaders.py and dataset_configs.py files already include preprocessing logic and dataset descriptions. Please use these as references to ensure consistency across datasets.
+ California housing dataset, Fuel_efficiency_dataset, Wine_quality_dataset, Insurance_dataset, and Time_series_dataset folders contain old implementation. You may use these for a reference.
